Why you might not see full names in GitHub's Contributors panel

- The GitHub contributors panel displays GitHub account logins (usernames). It will not necessarily show a person's full real name there.
- GitHub associates commits with a user account when the commit email matches an email on the user's GitHub account. Even if a commit's author.name contains a full name, the contributors list shows the account login.

How to make your full name visible to visitors (non-destructive options)

1. Set your GitHub profile Name and confirm the commit email(s)
   - Sign in → Settings → Profile → set the "Name" field to your full name.
   - Settings → Emails → add and verify any email addresses used in commits (e.g. edlamitrantej@gmail.com).
   - Once the commit email is verified and linked to your account, GitHub will associate those commits with your account and your profile page will show your Name.

2. Add this repository CONTRIBUTORS.md (this file)
   - This file provides immediate, visible attribution for project visitors without changing git history.

3. Use a .mailmap (optional)
   - Add a `.mailmap` file to canonicalize commit name/email pairs for tools that respect mailmap.

4. Rewrite history to change past commit metadata (destructive, avoid unless necessary)
   - Use `git filter-repo` or `git filter-branch` to change author/committer names/emails, then force-push; coordinate with collaborators. I can provide step-by-step instructions if you want to pursue this.
